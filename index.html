Xcratch MOD Extension

Grove Wrapper for micro:bit

Grove Shield for micro:bit で使う Grove モジュール向けに、 microbitMore の機能を分かりやすいブロック名で包むための拡張です。 読み込みURLは dist/groveShieldWrapper.mjs です。

読み込みURL

https://mnakaue.github.io/Xcratch-microbitmore-extension/dist/groveShieldWrapper.mjs

Xcratch での使い方

  1. Xcratch Editor を開く
  2. 「拡張機能を追加」を押す
  3. Extension Loader を選ぶ
  4. 上の URL を入力する
  5. Grove Wrapper のブロックを使う

備考

  • この拡張は microbitMore を土台にしています
  • 最初の版は、Digital / Analog / Servo の基本ラッパーから始めています
  • サーボは角度指定だけでなく、秒数を指定したゆっくり移動にも対応しています
  • 接続状態ボタンから micro:bit の Bluetooth 接続設定を開けます
  • I2C や UART の Grove モジュールは、個別に実装可否を確認して追加します
  • xcratch.github.io から localhost を直接読む確認は、ブラウザ制限で失敗します
